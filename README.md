
# FastAPI Crash Course

This repository contains the basic concepts and beginner-level implementation of FastAPI using Python.  
The project was created while learning FastAPI fundamentals including API creation, routing, request handling, and server execution.

## About FastAPI

FastAPI is a modern and high-performance Python web framework used for building APIs quickly and efficiently.  
It is widely used for backend development because of its speed, simplicity, automatic documentation, and support for asynchronous programming.

## Topics Covered

- Introduction to FastAPI
- Creating API routes
- GET requests
- POST requests
- Path parameters
- Query parameters
- Running server using Uvicorn
- Basic project structure
- Virtual environment setup

## Tech Stack

- Python
- FastAPI
- Uvicorn
